మేలిమి తెలుగు బలుకులు (బంగారు నాణేలు vocabulary)
1. కొన్ని మునుజేర్పులతో బలుకులు :
1. అడి (మిక్కిలి) : అడిగండ్లు, అడిగొట్టు, అడిత్రాంగుడు, అడియాస
2. అలన్‌ (గతము) : అలనాడు
3. అలన్‌ (మరల మరల) : అలవాటు, అలవోక
4. అసి (తక్కువ) : అసిగాయము, అసికోత, అసిబోవు, అసివాఱు
5. ఆ (తనవైపు) : ఆకొను, ఆకట్టుకొను, ఆపోవు, ఆగుబ్బు, ఆగుబ్బతి
6. ఇని / ఇను (కొంచెం ఎక్కువ) : ఇనుమిక్కిలి, ఇని-మనుమలు (మనుమల సంతానము)
7. ఎగన్‌ (పైకి) : ఎగఁగొట్టు, ఎగనూర్చు, ఎగందట్టు, ఎగఁదీయు, ఎగదోయు, ఎగంబడు, ఎగలాంగు, ఎగవేయు.
8. ఎడ / ఎడన్‌ (దూరముగా, విడివిడిగా) : ఎడఁబాయు, ఎడతెఱపి, ఎడపోక.
9. ఎదురు (ప్రతిగా) : ఎదురాడు, ఎదురే(గు, ఎదుర్కొను, ఎదురుతిరుగు
10. ఎస / ఎసన్‌ / ఎసల్‌ (ఎక్కువ, తక్కువ) : ఎసకొను, ఎసరేణు, ఎసవెట్టు
11. ఒడ / ఒడన్‌ / ఒన / ఒనన్‌ (దగ్గరగా, అనుకూలముగా) : ఒనగూడు ఒడఁగూడు.
12. క్రీన్‌ / క్రిన్‌ (క్రింద) : క్రీఁగంట, క్రీనీడ, క్రీగీటు (Underline).
13. దిగన్‌ (క్రిందకు) : దిగందీయు, దిగంబడు, దిగలాంగు
14. తోన్‌ (తోడుగా) : తోఁబుట్టువు, తోమాల, తోందెంచు
15. పడ / పెడన్‌ (అవతల, దూరముగా) : పెడమోము, పెడసరము, పెడంబాయు
16. పై / పైన్‌ (పైకి): పైకూటమి, పైకొను, పైసరము
17. మీదు (మీద) : మీందుకట్టు
18. మీన‌్ (మీంద) : మీగడ
19. మరు / మారు (తరువాతి, మరల, ప్రత్యామ్నాయముగా) : మరునాడు, మరుమాట, మా రాడు, మారుటుంగరము, మారుతల్లి
20. మున్‌ / మును (ముందు, ఇదివరకు) : ముంగడ, ముంగాలు, ముంగురులు, ముంగేలు, మునుకొను.
21. మై / మైన్‌ (తోడుగా) : మైకొను, మైవడి
22. లోన్‌ (లోపల, మనస్సులో) : లోఁగడ, లోవైనము
23. వెన్‌ / వెను / వెనుక (వెనుకకు, తరువాత) : వెనుగొను, వెనుదీయు, వెనుకాడు
24. సాన్‌ (సగము) : సాఁబాలు
25. మిడి (సైయెత్తు) : మిడిగుడ్లు, మిడిమేలము, మిడిమిడి జ్ఞానం
26. వైన్‌ / వై (దారి, దారిలో) : వైఁదొలఁగు
2. కొత్త మునుజేర్పులతో బలుకులు :
1. ఐన్/ఐ (అన్ని వైపుల/అన్ని వైపుల నుండి) : ఐకలి(ప్రకృతి), ఐఁదిలకన (సందర్శన), ఐనిల్క (పరిస్థితి)
2. తమూ(తమలో తాము) : తమూవల(internet), తమూబాసట (పరస్పర సహకారం), తమూగీటు (తమలో తాము గీసుకున్న పటము, కుమ్మక్కు)
3. అక(కానటువంటి) : అక+అక్కఱ = అకక్కఱ (అనవసరం), అక+కాఱియ = అకాఱియ (అహింస), అకపాటి (అన్యాయం)
4. ఔన్ (మంచి, positive) : ఔఁగాపు, ఔఁదలఁదాల్చు, ఔఁజందం
5. మన్ (మంచి, positive) : మందావి(మంచి తావి), మందనం (మంచి తనం), మంద్రోవ (సన్మార్గం)
6. సి/సీ(చెడు) : సీతావి, సీతనం, సీవాడుక(దురాచారము), సీజందం(కుసంస్కారము), సీకఱద(దుర్చుద్ది)
7. కై(కి, కు, కొఱకు) : కైచూచు (ప్రయత్నించు), కైచూడికి (ప్రయత్నం), కైవచ్చు (ఉపయోగపడు), కైరాక/కైరాకడ (ఉపయోగం, ప్రయోజనం)
8. ఓ(అతిగా, ఎక్కువగా) : ఓకల్పు (ఉపాసన), ఓచూడికి (గుచ్చి చూడటం)
9. తరు(తరువాత) : తరుకౌట(పర్యవసానం), తరుకుందు (పశ్చాతాపం), తరుతేను (ఆధ్యాత్మికత), తరుపదులు (teenage)
10. మఱి/మఱీ(అతిగా ఎక్కువగా) : మఱీక్రాలిక, మఱీదీమసము
11. బై(ప్రక్కన, దగ్గర, తోడుగా, సహాయముగా,ఉప) : బైప్రెగడ(ఉపమంత్రి), బైమెల్లరి(ఉపకార్యదర్శి), బైవీటు(ఉపాంగం), బైదాఁటు(to overtake)
12. అమా(అకస్మాత్తుగా) : అమామారిక, అమామార్పు = ఉత్సరివర్తనము (Mutation).
13. ఎల/ ఎలన్‌/ ఎల్‌(అన్నియు, అందఱు) : ఎలవంచి (సామాన్యం, సామాన్యుడు, సామాన్యురాలు), ఎలమైకోలు (అందరి ఒప్పుకోలు), ఎలసోంకు (pandemic), ఎలకార్తి (సర్వకాలికం), ఎలసీమ (సార్వదేశికం), ఎలమందిటి (సార్వజనీనం), ఎలతెలి (సర్వజ్ఞుడు), ఎలందారు (నిరంకుశం, నిరంకుశుడు, నిరంకుశురాలు)
14. వి(విడి, విడిగా, వేఱుగా, వేఱైన) : వికానువు (రూపాంతరం), వికానువించు (రూపాంతరీకరించు), వినాకువింపు (రూపాంతరీకరణ)
15. లా/లాన్‌(వేఱు, వేఱైన, స్వంతము కానట్టి) : లాసీమ (విదేశం), లాసీమరి (విదేశీయుడు), లాసీమటి (విదేశీయం), లాఁగానసం (పరలోకం)
16. సై(సిద్దము, సిద్దముగా, ముందే) : సైపడు, సైపరుచు, సైవాను, సైకాను, సైకుట్టు ఉడుపు (ముందే కుట్టిన బట్ట), సైలం (సై-ఉల్లం, సిద్ధమైన మనసు)
17. ఆయి(అదే) : ఆయిమాడ్కి = ఒకే మాడ్కి గల (సదృశము), ఆయి-చదువరులు = ఒకే చదువు చదివినవారు, సీమ = దేశము ; ఆయిసీమరి = అదే దేశమువాండు, ఆయి + ఊరి + లు » ఆయూరీలు = ఒకే ఊరువారు, కొల్వలి = మతము ; ఆయికొల్వటి = అదే మతమునకు చెందినవాండు ; ఆయికొల్వటీలు = ఒకే మతమునకు చెందినవారు.
18. సవి/సవీ (అట్ల అని) : సవితటం/ సవీతటం = అట్లని తట్టినది, పరిభావన (concept)

15. "మారి" భావార్ధకము "మారం" : పనిమారము (activity); బాసటమారము (సహాయ శీలము), చదువుమారము (అధ్యయన శీలము), నెమ్మనమారం (peacefulness)
16. అలవి/ అల్వి : చేయుటకు శక్యము, సాధ్యము యోగ్యము, అర్హము అని దీని అర్థము.
 చదువల్వి (readable); వినల్వి (audible); తినల్వి (edible); ఉండల్వి (livable), చేయల్వి (doable), చూడల్వి (Visible), వ్రాయల్వి (Writable), గెంటల్వి (expellable), క్రేయల్వి (boycottable), వెలివేయల్వి (excommunicable), కుదించల్వి (abridgeable),
17. అరిది/ అర్ది' ప్రత్యయము ఇది 'అలవి' ప్రత్యయమునకు వ్యతిరేకార్థకము.
 చదువరిది (unreadable); వినర్ది (inaudible); తినర్ది (inedible); ఉండర్ది (unlivable), చూడర్ది (invisible), చేయర్ది (undoable), వ్రాయర్ది (unwritable)
18. పాదు ప్రత్యయము : ఇది కూడ అర్థములోను, ప్రయోజనములోను 'అల్వి' ప్రత్యయము వంటిదే. కాని ఏమనఁగా దీనిని నామవాచకములకు చేర్చవలె.
 ఈవిపాదు (donable) దీవనపాదు (blessable); దండపాదు (worthy of salutation), వెలారపాదు (exposable), ఱోయల్పి (abhorable), కంటుపాదు (ద్వేషాస్పదం), వ్రాపైలపాదు (recordable), హంజరపాదు (ప్రవేశనీయం), కూర్మిపాదు (ప్రేమస్పదం, ప్రేమస్పదుడు, ప్రేమస్పదురాలు), నీడికపాదు (శరణ్యం, శరణ్యుడు, శరణ్యురాలు)
19. పఱ ప్రత్యయము : ఇది 'పాదు' ప్రత్యయమునకు వ్యతిరేకార్థకము 'తగనిది' అని దీనికి అర్థము. ఉదాహరణకు-
 ఈవిపఱ (ఈవికి తగని దాన అయోగ్యమైన), దీవనపఱ (దీవనకు తగని - ఆశీర్ అయోగ్యమైన), దండపఱ (దండము పెట్టుటకు తగని = నమస్కార అనర్హమైన)
20. ద/ఇద ప్రత్యయము : కాఁబడిన, చేయఁబడిన అని దీని అర్థము
 ఒప్పు + ఇదము→ఒప్పిదము = ఒప్పారినది
 తప్పు + ఇదము←తప్పిదము = తప్పినది
 చెయ్యు + ఇదము →చెయిదము = చేసినది.

 బెట్టు + ఇదుఁడు → బెట్టిదుఁడు = కఠినుఁడు

 క్రొవ్వు + ఇదము→క్రొవ్విదము = క్రొవ్వెక్కి ఆడిన మాట
 కోరు + ఇదము --> కోరిదము = అభీష్టము
 తెలియు + ఇదము --> తెలిదము = విదితము, విశదము
 విఱియు + ఇదము → విఱిదము = వికసితము
 ఎడారి +దం ఎడారిదం = ఎడారిగా మార్చబడినట్టిది, మారినట్టిది (desertified).

23. మాలు' ప్రత్యయము : రహితము (కలిగి ఉండనిది) అని దీని అర్థము

24. కము, ఇకము' ప్రత్యయము.
 కనైణి = కన్య బ్రహ్మచారి (virgin): కవైణికము = కన్యాత్వము (virginity)
 మిహి = గొప్ప; మిహికము = మహిమ
 తోఁబుట్టువు = సోదరుఁడు/ సోదరి; తోబుట్టుకము = సౌభ్రాత్రము
 తామట్టు = స్వార్థపరుఁడు, స్వార్థపరురాలు: తామట్టుకము = స్వార్థము, స్వార్థపరత

25. 'గము' ప్రత్యయము : దీనిని 'ఒక మొత్తము, గుంపు' అను అర్థములో ఎసవాడవలె.
 పరి = మనుష్యులు, ప్రజ: పరి+గమి, పరిగము = కమిటీ (committee)
 ఎన్నరి = ఎన్నుకొనువాఁడు, వోటర్: ఎన్నరి + గమి ఎన్నరిగము = నియోజకవర్గము (constituency)
26. ఓరు' ప్రత్యయము : దీనిని 'సంస్థ, వ్యవస్థ' అను అర్థములలో నామవాచకాలకు చేర్చవలసి యుండును.
 పాటి = న్యాయము : పాటి + ఓరు పాటియోరు = న్యాయవ్యవస్థ (Judiciary)
 మణియము = అధికారము; మణియ + ఓరు మణియోరు = ప్రాధికార సంస్థ (Authority)
 లెంక = సైనికుఁడు : లెంక + ఓరు లెంకోరు = సైన్యము
 కోలీవి = వాణిజ్యము : కోలీవి + ఓరు కోలీవియోరు = కార్పొరేషన్
 నెఱపు = నిర్వహణ : నెలుపు + ఓరు నెఱపోరు =నిర్వాహక వ్యవస్థ (Board)
27. 'ఆది' ప్రత్యయము : దీనిని ఒక మొత్తము, సమాహారము, సమూహము' అను అర్థము

 ఏలు = పరిపాలించుట; ఏలు + ఓజ = ఏలోజ = పరిపాలన విధానము. రాజనీతి
 మను = బ్రదుకు : నును + ఓజ = మనోజ = బ్రదుకుదెరువు. ఉపాధి (employment)
 కట్టు = నిర్మించు : కట్టు +ఓజ→ కట్టోజ = నిర్మాణ శిల్పము (వాస్తుశిల్పి
 గెఱ = గీత (స్ట్రోక్); గెఱ + ఓజ = గెఱోజ. గీత గీఁచు విధానము (font).
30. 'ఇ' ప్రత్యయము : 'కల్గిన, చేయునట్టి' ఆను అర్థము
 త్రెంపు = (తాళి) త్రెంచుట; త్రెంపు + ఇ = త్రెంపి = వితంతువు (తాళి త్రెంపుడు ఎవఱికైతే జరిగినదో ఆమె)
 తొలుకారు = మొదటి ఋతువు; తొలుకారు + ఇ→ తొలుకారి/తొలుకరి = తొలుకార్తికి సంబంధించిన వాన
 ఉబ్బు = నీరు ఉబికి వచ్చు; ఉబ్బు + ఇ = ఉబ్బి ఊబి = ఉబుకు కలిగినది.
 పొత్తు పొత్తు/బొత్తు = దట్టము = బొత్తు + ఇ బొత్తి = దట్టముగా ఉన్నది (కాగితముల సంపుటము)
 దరి = దగ్గర (గా) : కాపు = కాఁపుదల, రక్షణ; దరి + కాఁపు + ఇ దరిగాఁపి. = దగ్గరగా ఉండి కాఁచుకొనువాఁడు. అంగరక్షకుఁడు (bodyguard).
9. విశేషణ కల్పనకై వాడంబడు ప్రత్యయములు
“అ, ఇ, తి, టి/అటి, ఇటి, ఇంటి, ఆటి, పాటి, పారు, బారు, ఓక, పు/మ్బు, -సరి, -మారి, గొట్టు
 ఇ (ఊరు => ఊరి)
 తి (గోయి => గోతి)
 టి (తాడు => తాటి)
 పు/మ్పు (నిక్కము + ఎఱుక = నిక్కపుటెఱుక, నిక్కంపుటెఱుక)
 అ (అడాకులు => అడ్లాకుల)
 ఆటి, పాటి, పారు, బారు
 • పొడవు +ఆటి ౨ పొడవాటి. = సుదీర్షము (longish)
 • చిన్న +పాటి ఆ చిన్నపాటి = తనుమాత్రము (smallish)
 • ఱాయి +పారు => ఱాతిపారు =శిలామయము (rocky)
 • నేల +బారు-నేలబారు = హ్రస్వము, నీచము (short, mean)
 కొత్తవి:
 ఇ => కైకట్టు + ఇ , కైకట్టి = సాందర్భికము, ప్రొస్తావికము (contextual, relevant)
 టి
 • ఎసరేఁక = భావోద్వేగము (Emotion) ; ఎసరేంక + టి ౨ ఎసరేకటి = భావోద్వేగ పరమైన (emotional) ఎసరేఁకటి బెదిరింపు = emotional blackmail.
 • ఎర్మి (science) => ఎర్మిటి (scientific)
 ఆటి
 • వెల + ఆటి = వెలాటి = ఖరీదైన (costly)
 • విలువ + ఆటి = విలువాటి = అమూల్యమైన (precious)
 పు => ఆప
 • డెందము = హృదయము; డెందాప = హృదయమునకు సంబంధించినది, హార్షికము (cordial)
 • ఉలము = మనస్సు ; ఉల్లాప = మనస్సునకు సంబంధించినది, మానసికము (mental/ psychological)
 • వాయరము => వాయరాప = = భాషాసంబంధి (linguistic)
 • పొన్నము = దృశ్యము : పొన్నాప = దృశ్యసంబంధి (visual)
 ఆత & ఆమి
 • మై = శరీరము ; మై +ఆత = మయ్యాత = శరీరము నుండి పుట్టినది/ పుట్టినవాండు (సంతానము)
 • పారి =భూమి; పారి + ఆత = పారియాత = భూమి కొడుకు (అంగారక గ్రహము)
 • నెసరు = సూర్యుండు ; నెసరు+ ఆత = నెసరాత = సూర్యుని కొడుకు (శని)
 • నెల =-చంద్రుండు ; నెల + ఆత = నెలాత = చంద్రుని కొడుకు (బుధుండు)
 • పారి. =భూమి; పారి + ఆమి ౩ పారియామి = భూమిపు త్రిక (సీతాదేవి)
 • రా + ఆమి = రాయామి = రాజకుమార్తె
